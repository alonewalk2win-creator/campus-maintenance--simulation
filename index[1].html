01 / PROJECT OVERVIEW

From scattered registers
to a reliable workflow.

This project demonstrates the difference between handling campus complaints through a paper-style register and using a database-oriented process with clear rules. Both systems receive the same simulated complaints, so their results can be compared side by side.

The simulator is a teaching model—not a production maintenance database. Its results depend on randomized events and the selected settings.
